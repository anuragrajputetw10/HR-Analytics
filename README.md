# 👥 HR Analytics Dashboard

An interactive Power BI dashboard analyzing employee attrition and workforce composition across departments — built to help HR teams pinpoint roles and pay bands with the greatest retention risk.

## 🛠️ Tools Used
- Power BI (KPI Cards, Slicers, DAX)

## 📊 What the Dashboard Covers
- **1,407 employees** across HR, R&D, and Sales departments
- **16.0% overall attrition rate**
- Average **age**, **salary**, and **tenure** metrics
- Attrition breakdown by:
  - Education field
  - Age group
  - Salary band
  - Job role
  - Gender

## 🔍 Process
1. Cleaned and structured raw HR employee data
2. Built KPI cards for headcount, attrition rate, average age/salary/tenure
3. Segmented attrition across education, age, salary band, job role, and gender
4. Designed the dashboard to help HR quickly flag high-risk roles and pay bands

## 📈 Key Insight
Attrition risk isn't evenly distributed — certain job roles and salary bands show disproportionately higher attrition, giving HR a targeted starting point for retention efforts rather than a company-wide blanket approach.
